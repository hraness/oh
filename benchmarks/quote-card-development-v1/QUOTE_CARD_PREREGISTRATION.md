# Two quote-card development arms

This freezes the proposed design for **exactly two 100-question arms** on the existing exposed development selection. It is not an executable launch or spending authorization. Implementation, prompts, request profiles and source hashes must pass review and be pinned before the first new provider output. The [machine-readable design](memory-evolution-quote-card-development-preregistration-v1.json) binds the parent artifacts and exact private selection hash.

The reference is the immutable semantic nano **82/100** result. Both arms reuse its exact question/date and retained 96KB source context. There is no new index, retrieval change, fresh parent repeat, question replacement or access to the other 400 questions.

**A — validated quote cards.** One low-effort nano extraction request emits at most 32 cards and 16 optional operation plans, using the existing 8,192-token output cap including reasoning. Its JSON is bounded to 32KiB; each quote is bounded to 2KiB. Cards contain a source alias, exact quote and tag. The host validates every card, finds its unique exact quote occurrence, and derives the source digest, UTF-8 range, speaker and statement date from authenticated source. It preserves uncertainty, plans, examples and conflicting states. Relevance and relation tags remain model interpretations; an exact quote does not validate those interpretations. The existing combined-contract nano finalizer receives at most 16KiB of cards.

**B — the same cards plus deterministic operations.** Reuse A's exact extractor capture. A bounded pure interpreter reads admitted card references and exact quoted literals, then performs exact distinct-literal counts, sum/difference, compatible-unit conversion, complete-ISO-date intervals and ordering. Distinct literals use exact byte identity; it infers no relative dates, event filters or semantic duplicates. It executes no arbitrary code and trusts no model-supplied answer value. Unsupported or ambiguous operations produce explicit unresolved results. The same finalizer receives the same cards plus interpreter results, within the same 16KiB total context bound. Overflow fails the affected arm without trimming quotes. A receives neither operation plans nor results, making B-versus-A the planned component contrast.

Neither arm receives benchmark gold, evidence labels, categories, error lists or benchmark-specific examples. The existing nano profile is unchanged. Pin the complete logical matrix and extractor requests before the first output; pin downstream exact requests after authenticating their input captures and before dispatch. Preserve all prior requests and grades.

Malformed or truncated extraction, invalid quotes, or authenticated failures in a required stage score zero without repair, retry or original-context fallback. Valid empty cards may reach the finalizer and produce an abstention. All 100 cases remain planned per arm; an interrupted stage is incomplete and reports unattempted cases separately. The shared extractor is charged once physically and fully attributed to each arm's standalone cost comparison. Uncertain charges remain reserved.

The first six lexically ordered private question IDs form the predetermined service canary. Qualification checks transport, usage, custody and declared parser/failure handling, never answer correctness. Its first captures remain in the terminal comparison. Systematic client rejection, broken custody or a wave with zero successful physical responses stops new admission and drains active work.

Report A-versus-parent, B-versus-parent and B-versus-A, every category, and all failures, usage, unresolved exposure and latency. Development promotion requires both arms complete, at least **87/100**, at most one schema-stage failure in the proposed winner, and attributed exposure no greater than **$0.359352 per arm** (2.25 times the parent's $0.159712). Select higher accuracy, then lower attributed exposure, then A. These are practical development selection rules, not statistical superiority criteria. Report both arms even if neither qualifies.
