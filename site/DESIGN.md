# Oh public site

Oh serves developers evaluating inspectable local memory for agents. The page
starts with a concrete citation round trip, then explains the record model,
interfaces, reproducible benchmark evidence, installation and trust boundaries.

Use Nebula Sans and the saved Paper/Gruvbox appearance, one accent for actions
and terminal commands, flat reading surfaces, a calm single-column proof, and
ruled definition rows. Keep output monospace and scrollable within the terminal
on phones. Preserve real benchmark qualifications and the inspectable citation.
No organisms, floating records, hero textures, decorative topic art or fabricated
product screens. The shared organization footer follows document flow and aligns
with the 72rem content measure. Navigation remains visible on narrow screens.

Shared packages: design-kit v0.23.0 and site-footer v0.20.0; immutable marketing,
Paper and Lantern snapshots retain source provenance. Local composition stays
outside vendor files. Preserve saved appearance, no-JavaScript reading, keyboard
focus, forced colors, reduced transparency, and benchmark accessibility checks.

Delivery requires site checks, production build and browser gate under the
repository scheduler, CI, deployment and production verification. Source checks
alone are not visual or production evidence.
