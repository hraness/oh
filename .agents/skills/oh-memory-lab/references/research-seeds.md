# Research seeds (mechanisms, not phrasing)
- Visible evidence ledgers / chain-of-note before answering (Chain-of-Note, 2023; LongMemEval reader ablations show
  "extract then reason" helps small readers on multi-session and temporal).
- Time-aware context: session timestamps attached to every retrieved fact, sorted chronologically (LongMemEval
  time-aware query expansion; Zep/Graphiti bi-temporal edges; Honcho's dated derivations).
- Key-value / fact-level update resolution (Mem0 update operations; A-Mem note evolution): collapse superseded facts
  before the reader sees them.
- Instruction diet: small models degrade with long rule lists; test minimal instructions.
